## 越南住宅 IP、原生 IP、双 ISP，这三个词不是一回事

搞混这三个概念，很容易买到一台"越南 VPS"却发现账号环境照样被标记。

**住宅 IP** 说的是归属登记。IP 段挂在家庭宽带运营商名下，平台去查 Whois 或者做 IP 画像时，看到的是 ISP 家宽段，不是机房段。普通越南 VPS 卖的是数据中心 IP，段归机房，风控一眼能认出来。

**原生 IP** 说的是注册地和实际所在地一致。一台机器放在胡志明市，IP 注册地也是越南，这才叫原生。有些便宜方案拿别的国家的 IP 段广播到越南，位置对不上，解锁本地服务和流媒体就会出问题。

**双 ISP** 是更严的一层：ASN 归属和实际承载网络都来自家宽运营商，两头都对得上，不是只把 Whois 改好看。

丽萨主机这条线的具体属性是：独家小众的越南西贡邮电（SPT）宽带运营商 IP 段，双 ISP 原生住宅家宽静态 IP，机房在胡志明市。第三方测评用 Ping0 检测，测试 IP 被识别为家宽住宅 IP，历史记录干净、没有明显滥用痕迹；用 IPinfo 看，Company 字段显示为 ISP 类型，ASN 字段显示为非 ISP。测评方的解释是 ISP 名称存在空格差异，实际属于同一运营商体系，不影响双 ISP 住宅属性判断。

这段解释值得留意：ASN 字段和 Company 字段不一致时，不同风控系统可能给出不同判定，这也是"小众运营商段"的两面性。IP 段冷门意味着用过的人少、污染少；也意味着没有大量历史样本可参考，长期纯净度需要时间验证。重仓业务先小规模试，是这条线比较稳妥的用法。

顺带说清楚配套：每台机器 1 个 IPv4 + **免费 5 个原生越南 IPv6**。IPv6 对某些自建服务和检测有用，但绝大多数平台的风控还是盯 IPv4，别指望 5 个 IPv6 能当 5 个账号环境用。
